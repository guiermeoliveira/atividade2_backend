# *Atividade 2 - Backend*
### De: *Guilherme Henrique de Oliveira Souza*
#### Sistema Bancário e Sistema de Folha de Pagamentos

Este projeto foi desenvolvido como atividade prática da disciplina de Backend com a professora Fiama e o professor Atila onde o objetivo é desenvolver nossas habilidades em Programação Orientada a Objetos utilizando Java e conceitos como:

- *Abstração:* Definimos classes que vão suportar as classes de domínio onde um método exige que cada um valide sua "forma" antes de ser intanciado.
- *Herança:* Definimos que as classes de domínio herdarão os atributos das classes abstratas e exibam seus respectivos dados sem interferência.
- *Encapsulamento:* Utilização de `private` para atributos que garantem a imutabilidade sem intermediação dos métodos *get* e *set* impedindo a inconsistência de dados.
- *Polimorfismo:* a classe `Main` manipula os dados chamando seus metodos enquanto cada classe executa sua própria forma de execução.
